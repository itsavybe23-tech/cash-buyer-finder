# Cash Buyer & Builder Finder

A single-page tool for finding cash buyers and builders in Florida from public parcel and sales records. Open `index.html` through GitHub Pages.

Records load live in the browser: the Florida statewide tax roll for every county, plus the county property appraiser's own, fresher records for Lee, Sarasota, Miami-Dade, Manatee, Lake, Volusia, Charlotte and Marion. Charlotte publishes no sale prices, so its sales take the state roll's price when the state has the same sale and show "price not published" otherwise.
